# iOS / iPadOS App 图标清单 —— 一行一个
#
# 三种写法：
#   微信                          # 按名字搜。靠苹果的相关度排序，简单 App 一般都对
#   元气壁纸 = 6448843762          # 钉死 ID。**同名竞争 / 搜错过一次的应用必须这么写**
#   卡通农场 = 506627515@us        # 钉死 ID + 区号。**要国际版时必须这么写**
#
# 什么时候必须钉 ID：查出来的 [0] 不是你真正想要的那个 App。
# 实测三例：
#   元气壁纸 -> [0]「元气桌面壁纸」是另一个 App；[1] 才是要的（id=6448843762）
#   Filmix   -> [0]「Filmix相机」；[1]「Filmix - AI影视库重命名整理刮削」才是要的
#   人人视频  -> App 已改名「人人追剧」（id=6774511125），搜「人人视频」会跳到别处
#
# 为什么要区号：App Store 的区号决定上架范围。搜「卡通农场」cn 区只出腾讯代理的
# 国服版（com.tencent.hayday，2024 年就停更了），国际版 Hay Day（Supercell 出品，
# id=506627515）在 cn 区根本查不到，得写 @us。
# 不想写区号也行 —— 脚本会在查不到时自动扫 us/sg/hk/jp/de 找。
#
# ⚠️区号回退只在「没写@区号」时生效。**显式写了 @cn 就不回退**，查不到就是查不到。
#
# 实测 Telegram 的坑：官方正版（Telegram FZ-LLC，id=686449807）在 App Store
# 中国区**搜不到也 lookup 不到** —— 被下架了。国区搜「Telegram」出来的全是
# 仿冒马甲（「飞机-安全加密聊天软件」id=6478190856、Telegram Plus 等一堆）。
# 国际版必须写 @us钉死，别指望搜名字能搜到。
#
# 想找某个 App 的 ID：在 App Store 里点分享按钮，链接里 id= 后面那串数字。
#
# 改完保存，双击 fetch-ios-icon.bat 即可。已下载过的会自动跳过，
# 想重下就删掉 icons/apps/ 里对应的 png。
